# 我的交易本 · 个人股票交易记录网站

单文件本地网站：**双击 `index.html` 即可使用**，无需安装、无需服务器。所有数据保存在浏览器本地（localStorage）；**实时行情与舆情功能需要联网**（免费公开接口，无需注册）。

**线上地址（GitHub Pages，手机/电脑均可访问）**：https://langzaijianghu883-ux.github.io/trading-book/

> 更新网站：本地修改 `index.html` 后执行 `git add . && git commit -m "更新" && git push`，约 1 分钟后线上生效。

## 使用方式

1. 双击打开 `index.html`（建议使用 Chrome / Edge）
2. 首次打开自动载入初始数据（11 个持仓、成本价全部已录、证券代码已验证，来自 2026-08-21 的真实备份）
3. 日常操作：
   - **录入交易** → 切到「交易流水」页填表提交，自动更新持仓、成本、余额并重算全部指标
   - **出入金** → 「交易流水」页「出入金记录」面板录入（银证转账、追加资金、提现），自动增减可用余额，可在列表删除回滚；仪表盘新增「净投入」卡片（累计入金 − 累计出金）
   - **分红** → 「交易流水」页「分红信息」面板：先选持仓点「查询」自动拉取**分红方案**（报告期、方案、除息日、股权登记日、税前每股、状态，数据来自东方财富，仅 A 股）；「我的分红记录」录入**到账净额**（税后），自动计入可用余额，可删除回滚；仪表盘新增「累计分红」卡片
   - **补录成本价** → 切到「持仓」页，在"成本价"列点击输入（之前已录成本会在买入时自动按加权平均更新）
   - **填证券代码** → 「持仓」页"代码"列输入（如 `600363`、`01548`，或 `sh600363`、`hk01548` 写法），保存后自动接入实时行情
   - **手动估值** → 未填代码（或行情不可用）的标的，"现价"列可手动修改，作为无行情时的基准价
   - **手动调余额** → 仪表盘"可用余额"卡片右上角「调整」（盘点/纠错用，会作为一条"调整余额"记录入账）

## 实时行情

- **数据源**：腾讯行情接口（主，脚本加载方式，支持 A 股 / 港股 / ETF）；东方财富批量接口（备用）
- **刷新**：页面打开自动拉取一次；仪表盘顶部可开关「自动刷新」并调整间隔（30 秒 ~ 5 分钟），也可点「⟳ 刷新行情」手动刷新
- **生效范围**：凡填写了证券代码的持仓，其**现价、市值、浮动盈亏、总资产等全部指标自动改用实时价计算**；行情栏显示最后更新时间与覆盖标的数
- **注意事项**
  - 代码格式：6 位 A 股（自动识别沪/深）、5 位港股；科创板（688）、沪 ETF（5 开头）自动归沪市，创业板（3 开头）、深 ETF（1 开头）自动归深市
  - 收盘后行情为当日收盘价；非交易时段显示最近交易日数据（行情栏会标注日期）
  - 代码填错或接口异常时，行情栏会提示，该标的自动回退到手动基准价，不影响其他功能
  - 初始数据已预填 8 个持仓代码（迈威生物、联创光电、成都先导、消费ETF、惠城环保、ST京蓝、新恒汇、金斯瑞港股）；麦格数据、赛维电子、恒生科技 3 个未填（代码不明确，请在持仓页自行确认后填写）

## 持仓舆情

「舆情」页收集持仓个股的公告与资讯，辅助判断消息面：

- **交易所公告**（主源，按证券代码精准抓取，仅 A 股）：如"控股股东股份被冻结"这类直接影响股价的公告会第一时间列出；点击标题直达公告原文
- **焦点资讯流**（辅源，按持仓名称匹配）：当日要闻 + 焦点栏目中涉及持仓的新闻
- 页面已设置 `no-referrer` 策略绕开东方财富对非白名单来源的反爬拦截（HTTP 567）；接口异常时页面顶部会**明确列出失败原因**（含状态码翻译），不再静默
- **情绪标签**：每条内容按关键词规则粗判「利好 / 利空 / 中性」（利空词优先），仅供参考，请以原文为准
- **兜底**：每张卡片提供「东财搜索」「百度搜索」按钮，直接查看该标的完整搜索结果
- 页面顶部显示上次收集时间与统计（公告 N 条 · 资讯 N 条 · 失败 M 项），可按标的筛选、开关「仅显示相关」；进入页面首次自动收集，之后可点「⟳ 重新收集」
- 港股与未填代码的标的没有公告源，仅能靠资讯流匹配
- **如舆情为空**：优先检查持仓是否已填证券代码（公告源只认 A 股代码）；页面顶部的失败明细会指出是接口超时还是代码问题；广告拦截插件可能屏蔽财经数据域名，可关闭后重试

## 指标说明

| 指标 | 计算方式 |
|---|---|
| 持仓市值 | Σ(数量 × 现价)，现价优先取实时行情，无行情时用手动基准价 |
| 总资产 | 持仓市值 + 可用余额 |
| 持仓成本 | Σ(数量 × 成本价)，未录成本的持仓不计入并标注"未录成本" |
| 浮动盈亏 | 持仓市值 − 持仓成本；盈亏率 = 盈亏 ÷ 成本（随实时行情实时变动） |
| 已实现盈亏 | Σ 各笔卖出 (卖出价 − 当时成本) × 数量 − 手续费（成本未知的卖出不计入） |
| 加权平均成本 | 买入时 (原成本×原数量 + 买入价×买入量 + 手续费) ÷ 新数量；首次买入（或成本未录）以买入价作为初始成本 |
| 仓位分布 | 各持仓市值 ÷ 总市值（环形图） |

A股习惯：**红 = 盈利/涨，绿 = 亏损/跌**。

## 数据安全

- 数据存于浏览器 localStorage，**清除浏览器数据会导致丢失**，请定期点右上角「导出备份」下载 JSON 文件
- 「导入」可恢复备份（覆盖当前数据，导入前会自动提示；旧版备份自动兼容升级）
- 「保存初始」把当前数据固化为**初始状态**：此后点「重置」恢复到这份数据（而非出厂数据）——你的每一次修改都可以被永久保留
- 「重置」恢复初始状态（默认出厂数据；若曾点过「保存初始」则为保存时的数据，双重确认）
- 交易流水中的每笔交易可单独删除，删除时自动回滚持仓数量、成本与余额（资金重放，任意删除顺序一致）

## 统计分析

- 导航「统计」页（快捷键 `5`）：
  - **汇总卡**：已实现盈亏合计、累计分红、净投入、交易胜率、盈亏比、最大单笔盈亏
  - **总资产趋势图**：基于每日快照（每天打开页面自动存档一次，也可点「更新今日快照」手动覆盖当天），至少 2 天快照后开始绘制
  - **月度汇总表**：每月净投入、已实现盈亏、分红、卖出笔数（胜数）、月末总资产
- 快照数据保存在 localStorage，随备份一起导出

## 其他功能

- **K 线图**：持仓页每行「K线」按钮，日K/周K切换，前复权，含 MA5/10/20 均线与成交量（东方财富主源 + 腾讯备用源，自动重试）
- **行业分布**：持仓页「按公开信息自动填行业」一键填充（东方财富数据中心·证监会行业分类，只填空白的，已填的跳过；代码与名称不符时自动提示），也可手动在"行业"列编辑；仪表盘按市值显示行业分布条形图（可暴露仓位集中度）。ETF/港股无行业数据，需手动填写
- **导出CSV**：右上角「导出CSV」，交易/出入金/分红合并导出（UTF-8 BOM，Excel 直接打开）
- **PWA**：线上访问时自动注册 Service Worker，手机浏览器可"添加到主屏幕"，离线也能打开页面（数据接口需联网）
